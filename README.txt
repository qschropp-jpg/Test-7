Schulrundgang – Testversion mit 65 Standorten

index.html: 360-Grad-Rundgang fuer PC und Mobilgeraete (Marzipano).
vr.html: experimentelle immersive WebXR-Ansicht fuer HTC Vive Focus 3.

WICHTIG: Alle Dateien und Ordner hochladen: index.html, vr.html, tour.js, scenes.js, vendor/, images/, vr-images/.

PFEILE KORRIGIEREN:
In index.html auf „Pfeile korrigieren“ klicken. Danach einen falschen Pfeil anklicken und auf die gewuenschte Stelle im Panorama klicken. Die Position wird lokal im Browser gespeichert. Ueber „Korrekturen exportieren“ koennen die Anpassungen als JSON gesichert werden. Die lokale Speicherung wird nicht automatisch auf andere Geraete oder Besucher uebertragen. Sende die exportierte JSON-Datei fuer eine feste Einbindung in den Rundgang.

VR: Die Panoramen in vr-images/ sind auf 2048 x 1024 Pixel verkleinert, um GPU-Speicher auf der Vive zu sparen. Das VR-Rendering muss auf der Vive Focus 3 getestet werden. Bei schwarzem Bild den angezeigten Status oder die Browser-Konsole pruefen.
